# Study methods and gentle gamification

The first study slices add source-checked activities, a three-step practice flow,
optional participation achievements and a voluntary review list. These are a
supervised prototype, not validated assessment or ADHD/dyslexia treatment.

## Six study choices

| Choice | Activity | Example using the original sharing passage |
| --- | --- | --- |
| Help me remember | One retrieval question; optionally cover the passage | “How many counters does each person receive?” |
| Show me, then help me try | A short worked example followed by labelled practice | Follow the equal-sharing example, then try a related question |
| Let me teach you | Explain reasoning in your own words | Describe why equal groups give each person the same amount |
| Make it concrete | A verbal scene or object-based explanation, then a question | Picture counters being shared among people |
| One small mission | One manageable task and content question | Find the equal-sharing idea, try it, then reflect |
| Bring it back | Revisit an approved idea using retrieval practice | Return to an idea from the optional review list |

Generated wording varies. All card content, including the suggested answer and
hint, passes structural/source checks and a semantic review before publication.
The method-specific scaffolding is added explicitly: teach-back asks for reasoning,
recall does not display an extra worked example, and practice examples are labelled.
Verbal scenes do not generate images. Choice of challenge changes the request
between familiar practice and a gentle connection; it does not change age access
or participation credit.

## Explore → Try → Reflect

1. Choose the passage in the reader, a study method and a comfortable challenge.
   Select **Start a small quest** (adult spaces say **Start a study session**).
2. **Explore:** read or listen to the original passage and any worked example.
   There is no countdown. Select **Ready to try** when ready.
3. **Try:** optionally cover/uncover the passage, type up to 800 characters,
   listen to the question, ask for a hint or select **Show me — help is welcome**.
   Spoken answers remain pending local dictation.
4. A checked response or explicit answer support opens **Reflect**. Notice that
   you tried, used support or want another try. These choices are not grades.
5. Optionally choose to revisit in one, three or seven days, then finish. The
   same completion credit applies whether you used hints/audio or typed an answer.

Feedback explores the learner's meaning and should not correct spelling or typing
in this mode. It is checked model guidance, not marking or proof of understanding.
For a worked example, feedback receives that exact practice question and its
checked reference answer. A separate review must confirm consistency with the
activity, so the source passage's example numbers are not substituted silently.
For that comparison the model receives the checked practice reference as its
evidence, rather than mixing it with the original example. The quotation is labelled
**Checked practice reference**, not presented as a literal excerpt from the book.
If model wording starts demanding full-sentence writing or claiming understanding,
Piet replaces it with explicit reference-comparison support and checks that support
through the same gate. It does not pretend to have assessed the learner.
If a response is withheld, use the original, a hint, explicit answer support or a
person's help. Do not treat withheld feedback as the learner failing an activity.

**Take a break** pauses the card without a timer or lost credit. Resume at your
own pace. Server-side cards expire after one hour and are held in a bounded
128-card memory cache; long breaks, page reloads or server restarts can require a
fresh activity. An unfinished activity is not saved for resumption across visits.

## Optional participation, not performance ranking

Open **Progress and celebration choices** to control:

- **Show participation progress and achievements:** turn off to stop adding new
  completion counts/achievements and hide their display. Study and voluntary
  review scheduling still work.
- **Celebration style:** a quiet message, a small static garden or no celebration.
  Adults start with no celebration; other spaces start with the garden choice.
  Display choices persist as browser preferences.
- **Remember participation and review references on this browser:** off until
  explicitly selected. See storage below.
- **Clear this space's practice progress:** reset its participation totals,
  achievement codes and review references. It does not delete books or reviews
  in the owner library.

Achievements recognise trying an idea, asking for support, reflecting and trying
another explanation. The garden displays up to six plants; the optional count
can continue beyond that. There are no public leaderboards, streak penalties,
speed rewards, prize purchases, random rewards, sounds or flashing celebrations.
Reduced-motion preferences are respected. There is no mastery score, personal
ability ranking, or reward for avoiding assistance.

## Review list and storage

After completion, **Ideas to revisit** can hold the approved source references
you chose. You can return earlier or later than the chosen date. Dates are not
deadlines and there are no notifications or background reminders. Each revisit
generates a fresh checked activity. This is a user-selected spacing scaffold,
not an adaptive spaced-repetition algorithm based on demonstrated mastery.

Participation data stays in browser memory by default. Opt-in saving stores only
completion totals, fixed achievement codes, source IDs/fingerprints and review
dates. It does not save typed responses, card questions, generated feedback,
scores or diagnoses. Turning saving off removes the saved record while retaining
the current in-memory session. If browser storage is unavailable, the interface
reports it rather than promising a successful save/removal.

Saved state is scoped to the library installation and age band, **not an
authenticated person**. People using the same browser and age space share it;
clear it or use separate browser/OS accounts as appropriate. Learner profiles,
cross-device sync and private progress accounts remain planned. Old review
references disappear when a passage is withdrawn, revised or no longer age-eligible;
earned participation is not reduced. The list is bounded to 50 references and
ignores malformed or more-than-a-year-old/out-of-range dates.

## Limits and follow-on slices

The prototype does not judge pronunciation, certify understanding, assign official
marks, diagnose learning needs, or verify that a learner actually completed an
activity. Any local count can be edited by someone controlling that browser.
Feedback and examples can still be wrong; use the original and educator review.

Next work includes supervised learner evaluation, stronger account isolation,
reliable assessed progress before adaptive scheduling, offline dictation, and
reviewed visual supports. See [roadmap](../ROADMAP.md), [privacy](PRIVACY-AND-VALIDATION.md)
and [validation evidence](../VALIDATION.md).
